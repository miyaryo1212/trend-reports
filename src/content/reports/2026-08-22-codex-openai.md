## 公式アップデート

### GPT-5.6 Sol の値下げ

8月21日付で、GPT-5.6 Sol の API 価格およびクレジット価格が今後3か月間にわたり20%超引き下げられました。

[ソース](https://openai.com/index/)

### Apple Messages プラグイン

macOS 版 ChatGPT デスクトップアプリで、Messages の閲覧・検索・送信を Codex / ChatGPT Work から実行できるプラグインが提供されました。対象は全プランです。

[ソース](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)

### Sites の共同編集

Site の所有者が、同一ワークスペースのメンバーを編集者として招待できるようになりました。招待された編集者は更新・バージョン保存・公開が可能です。

[ソース](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)

### Site URL の変更対応

再デプロイなしで ChatGPT ホストの Site アドレスを変更できるようになりました。旧 URL は新 URL へリダイレクトされます。

[ソース](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)

### Computer History の欧州提供

EEA・スイス・英国の ChatGPT Pro / Business / Enterprise 向けに、macOS デスクトップアプリの Computer History が提供開始されました。既定はオフで、利用には Memories が必要です。

[ソース](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)

### Codex スレッドの読み取り専用スナップショット共有

ローカルの Codex スレッドについて、静的なスナップショットを macOS デスクトップアプリから共有できるようになりました。共有したスナップショットは失効させることができます。対象は全 Codex プランです。

[ソース](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)

### ピン留めチャットのデバイス間統一

ChatGPT デスクトップアプリと iOS の間で、ピン留めしたチャットが同期されるようになりました。

[ソース](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)
