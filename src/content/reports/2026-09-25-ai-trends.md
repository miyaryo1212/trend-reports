## 公式アップデート

本日は Step 0 の公式RSS/フィードからの新着取得が0件だったため、以下は Step 1 の抽出結果に基づく事実の列挙である。各項目のURLは抽出時に付与されたものを記載する。

### Anthropic「Project Swap」公開 (エージェント同士の蔵書取引実験)

Anthropic が 9月24日、社員201人の蔵書の交換取引を Claude エージェント同士に代行させた実験「Project Swap」を公開した。報告では、交渉そのものの巧拙よりも「依頼者本人の好みを正しく理解すること」が最大のボトルネックだったとされている。

[ソース](https://www.anthropic.com/research/project-swap)

### ChatGPT Ads が東南アジア6か国・台湾に拡大 (OpenAI)

OpenAI が 9月23日、ChatGPT Ads の提供地域をインドネシア・マレーシア・フィリピン・シンガポール・タイ・ベトナム・台湾に拡大した。広告表示の対象は Free / Go プランのみで、Ads Manager のセルフサービス出稿も同地域で利用できる。

[ソース](https://openai.com/index/chatgpt-ads-expands-southeast-asia-taiwan)

### MentalHealthBench 公開 (OpenAI)

OpenAI が 9月23日、メンタルヘルス相談を想定した現実的な会話でAI応答の有用性と安全性を測る専門家監修のベンチマーク「MentalHealthBench」を公開した。

[ソース](https://openai.com/index/introducing-mentalhealthbench)

### Daybreak プログラムをウクライナ政府に開放 (OpenAI)

OpenAI が 9月23日、Daybreak プログラムをウクライナ政府に開放した。民間インフラのサイバー防衛支援としてアクセス範囲を拡大するもの。

[ソース](https://openai.com/index/openai-extends-cyber-access-to-ukraine-for-civilian-defense)

### OpenAI Academy が2周年

OpenAI が 9月23日、AIスキル教育プログラム OpenAI Academy の2周年を発表し、対象コミュニティをさらに拡大する方針を示した。

[ソース](https://openai.com/index/two-years-of-openai-academy)

### OpenAI と Grab が「GO Forward with AI」開始

OpenAI と Grab が 9月23日、東南アジアのパートナー3万人に実践的なAIスキル研修を提供するプログラム「GO Forward with AI」を開始した。

[ソース](https://openai.com/index/grab-openai-ai-skills-southeast-asia)

### GPT-6 Astra の企業導入事例公開 (Harvey / invideo / Parallel / Ringg)

OpenAI が 9月23日、GPT-6 Astra の企業導入事例を相次いで公開した。Harvey は法務ドラフト、invideo はカラーグレーディングの3倍高速化、Parallel は調査時間・コストの半減、Ringg は顧客電話の最大65%の自動解決を報告している。

[ソース](https://openai.com/index/harvey-from-context-to-confidence-with-astra)
