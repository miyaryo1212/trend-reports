## 公式アップデート

### Computer History (macOSデスクトップアプリ)

macOS デスクトップアプリにオプトイン機能「Computer History」が追加された。有効化すると、アプリやサイトを横断した作業履歴がメモリおよびタイムラインとして記録され、ChatGPT と Codex から参照できる。対象は Pro / Business / Enterprise プランで、EEA・スイス・英国は対象外。

[ソース](https://openai.com/news/)

### Ultrafast モード (GPT-5.6 Sol)

Cerebras のインフラで提供される新しいサービス階層「Ultrafast」が、OpenAI API で限定プレビューとして開始された。GPT-5.6 Sol を対象に、標準ティア比で最大14倍、最大 750 output tokens/秒のスループットを謳う。

[ソース](https://openai.com/news/)

### The builder's guide to GPT-5.6

GPT-5.6 を使うアプリケーション開発者向けのガイドが公開された。Responses API での推論の保持、ネイティブ compaction、マルチエージェント構成、Programmatic Tool Calling を組み合わせたコスト削減手法を扱う。ARC-AGI-3 のスコアが 13.3% から 38.3% に向上した例や、プロンプトキャッシュの TTL が最低30分に延長された点も示されている。

[ソース](https://openai.com/news/)
