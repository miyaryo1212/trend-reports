## 公式アップデート

### OpenAI「Decisions API」が正式提供 (GA) (10/22)

OpenAIが Decisions API を一般提供に移行した。

- ベースモデルは gpt-6-luna
- 料金は入力100万トークンあたり $0.10
- 質問ごとの画像入力、input_json による構造化データ入力、共有入力のプロンプトキャッシュに対応
- 1リクエストあたりの質問数上限を 200 から 400 に拡大

[ソース (OpenAI)](https://platform.openai.com/docs/)

### AnthropicがAgent SkillsをAgentic AI Foundationに寄贈 (10/22)

Anthropicが、オープン標準 Agent Skills を Linux Foundation 傘下の Agentic AI Foundation (AAIF) へ寄贈した。

- 寄贈対象は名称、ロゴ、GitHub組織、agentskills.io ドメイン
- 70 超のプラットフォームが採用。公開スキルは 100万、インストールは約 2.8億件
- MCP に続く AAIF への寄贈

[ソース (Anthropic)](https://www.anthropic.com/news)

### Anthropic研究「Claudeによる実世界ソフトウェアの形式検証」 (10/22)

AnthropicがTheoremと共同で、実在するOSSライブラリの形式検証に関する研究を公表した。

- OSS-Fuzz 対象の 123 ライブラリ、239 エントリポイントを対象に、RISC-V アセンブリレベルで非クラッシュ性を証明
- Rocq による証明は約 1.8億行
- libexpat の CVE-2026-56132 を再発見
- 証明とスキルを GitHub で公開

[ソース (Anthropic)](https://www.anthropic.com/research)

### OpenAIが最大300億ドルの資金調達を協議 (CNBC報道、10/22)

CNBCが、OpenAIによる最大 300億ドルの資金調達協議を報じた。

- UAE の投資家と Coatue が主導。プレマネー評価額は 1.25兆ドル
- 2027年の IPO に向けたブリッジ資金と位置づけ
- UAE からの計算資源確保に関する商業契約も並行して交渉中とされる
- OpenAI からの正式な公表は本日時点でない

[ソース (CNBC)](https://www.cnbc.com/)

### Microsoft、ConnectWise供給網攻撃をエージェント型AI「ARTEX」利用のStorm-0940と特定 (10/21)

Microsoftが、ConnectWise を経由した供給網攻撃の攻撃主体を中国系グループ Storm-0940 と特定し、その手法を公表した。

- Go 製のエージェント型ペンテスト基盤 ARTEX を攻撃に使用
- 2,250 超のテナントに対し、毎分 2,900 サインインの速度で攻撃
- 初期標的化から特権取得まで 3時間未満の事例あり

[ソース (Microsoft Security)](https://www.microsoft.com/en-us/security/blog/)

### Walmart「Agent Gateway」とAgent Profiles (10/21)

Walmartが、承認済みのAIエージェントによる買い物代行を受け入れる Agent Gateway と Agent Profiles を発表した。

- ChatGPT、Gemini、Muse などのエージェントが MCP 経由で Walmart / Sam's Club の在庫検索と購買を代行
- 顧客は支出上限と購入承認を設定可能
- カード情報はエージェントに開示されない
- エージェント購買を遮断する Amazon とは対照的な方針

[ソース (Walmart)](https://corporate.walmart.com/news)

### UberがChatGPT Workを全社3万人超に展開 (10/22)

Uberが ChatGPT Work を 1,000人のパイロットから全社展開に拡大した。

- 対象は全社 3万人超
- 既定モデルは GPT-6.1 Sol
- Google Drive、Gmail、Slack などと連携
- エージェント型プラットフォームとしては初の全社導入

[ソース (OpenAI)](https://openai.com/news/)

### Canva初の自社画像生成モデル「Canva Craft」 (10/22)

Canvaが初の自社開発画像生成モデル Canva Craft を公開した。

- 人間が作成したテンプレートで学習
- レイアウト計画から生成へ進む2段階構成
- 最大 2K、30 種のアスペクト比に対応
- Dream Lab で全ユーザーに提供。Canva API でも利用可

[ソース (Canva)](https://www.canva.com/newsroom/)

### Google Meetのリアルタイム音声翻訳が63言語に拡大 (10/22)

GoogleがGoogle Meetのリアルタイム音声翻訳の対応言語を 63 言語に拡大した。

- Gemini 3.5 Live Translate により任意の言語ペア間で翻訳
- 話者言語の自動検出に対応
- Rapid Release で展開開始
- 基本プランは1会議あたり 90分まで

[ソース (Google Workspace Updates)](https://workspaceupdates.googleblog.com/)

### Gemini APIでプレビューモデル群が提供終了 (10/22)

Gemini API で複数のプレビューモデルがシャットダウンされた。

- 対象は veo-3.1-generate-preview 系の 3 モデルと gemini-omni-flash-preview
- 移行先として gemini-omni-1.1-flash を推奨

[ソース (Gemini API)](https://ai.google.dev/gemini-api/docs/changelog)

### Google Docs「Docs Live」でモバイル音声からの文書作成 (10/21)

GoogleがGoogle Docsのモバイル向け機能 Docs Live を発表した。

- 音声入力だけで構造化された文書を作成

[ソース (Google Workspace Updates)](https://workspaceupdates.googleblog.com/)

### OpenAI「What FDE means at OpenAI」 (10/22)

OpenAIが Forward Deployed Engineering (FDE) チームの役割を解説する記事を公開した。

- モデルの能力と実際の導入の間にある「デプロイメントギャップ」を埋める方針を説明

[ソース (OpenAI)](https://openai.com/news/)
