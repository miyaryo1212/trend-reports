## 公式アップデート

### Codex CLI 0.166.0 正式版

前回のレポートで取り上げたアルファ版に続き、0.166.0 の正式版が 2026-10-29 (UTC) に公開されました。リリースノートの主な内容は次のとおりです。

**新機能**

- **トランスクリプトのキーボード選択**: キーボードでトランスクリプトを選択できるようになりました。単語・行・ページ単位の移動、検索、ショートカットの変更に対応します。(#57221〜#57224)
- **Markdown 表示の統一**: 非同期の質問、選択肢、回答、トランスクリプトの返信で、Markdown を同じ形で表示するようになりました。(#57259, #57292)
- **GPT-6.1 Terra の追加**: 同梱のモデルカタログ、Vertex AI のカタログ、Amazon Bedrock のカタログに GPT-6.1 Terra が加わりました。(#57293)
- **`codex queue --resume`**: メッセージをキューに入れたあと、読み込まれていないスレッドを再開できます。(#57232)
- **安全ブロック時の案内**: TUI で、安全上の理由でブロックされたときの説明がわかりやすくなりました。より安全な次のプロンプトを候補から選べます。(#57363, #57365)
- **`codex doctor --network-only`**: 設定・接続・WebSocket に絞って診断できます。(#57606)

**バグ修正**

- スレッドを再開・フォークしても、承認済みの承認設定と権限設定が保たれるようになりました。(#57227)
- 削除した入力欄のテキストを復元するとき、ローカル画像の添付も残るようになりました。(#57502)
- macOS で、インストールが使用中のときや、パスに ASCII 以外の文字が含まれるときに、スタンドアロン版の古いリリースを片付けられない問題を修正しました。(#57503)
- 親スレッドのアーカイブを解除すると、そこから生成された子孫スレッドも復元されるようになりました。(#57635)
- app-server で、スレッドの起動時と終了時に起きる競合状態を修正しました。完了したランタイムもすぐに解放します。(#57787, #57788)
- TUI の再接続処理を改善しました。オフラインでも `/quit` と `/exit` が使えます。(#57820)
- 再開・フォークの後も推論トークンの集計を引き継ぐようにして、コンパクションが早すぎるタイミングで走らないようにしました。(#57839)

**その他 (Chores)**

- Bazel のビルドを、ソースからビルドした V8 に切り替えました。Rust バインディングはターゲットに合わせたものを使い、Windows のネイティブ MSVC アーカイブにも対応します。(#57164, #57269, #57644, #57832)
- スタンドアロンの executor を、CLI と app-server の正規リリースパッケージに含めるようになりました。(#57837)
- 開発用とリリース用のビルドで使うバージョンを Node.js 24.22.1 と Rust 1.95.0 に揃えました。(#57168, #57373)

変更履歴には、このほか FedRAMP の API キーを政府向けエンドポイントに既定で振り分ける変更 (#57178)、プロバイダー設定で GCP のプロジェクトとロケーションを指定できるようにする変更 (#56560)、Guardian のコンテキスト構成の整理 (#56477 など) も含まれています。
