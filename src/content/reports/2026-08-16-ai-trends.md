## 公式アップデート

### Qwen3.8-27B

Alibaba Qwen が 8/14 に 27B のマルチモーダル密モデル Qwen3.8-27B を Apache 2.0 で公開した。コンテキスト長は 262K。Terminal-Bench 2.1 で 73.0、OSWorld-Verified で 84.3 を記録している。

### DeepSeek-V4-Pro

DeepSeek が 8/14 に V4-Pro の正式版を公開した。同時に API 価格を最大 1,100% 引き上げ、ピーク / オフピークの時間帯別課金を導入している。

### OpenAI Ultrafast

OpenAI が Cerebras 上で GPT-5.6 Sol を最大 14 倍速・750 tok/s で動かす新しいサービスティアを、API 限定のプレビューとして提供開始した。

### ChatGPT 欧州で広告開始

OpenAI が 8/15、EEA およびスイスの Free / Go ユーザーに対し 8 月中に広告表示を開始すると通知した。当初は文脈ベースの広告のみで、パーソナライズド広告はオプトインが必要となる。

### Debian LLM寄与の可否投票

Debian が 8/15、LLM 生成コントリビューションの扱いを問う投票を開始した。全面禁止から開示義務付けまで 9 つの案が提示されており、締切は 8/28。

### Grok の SpaceX 全社データ学習

Musk が SpaceX の全社会議で、Grok を社内情報全体で学習させる方針を表明した。社員を「Grok の親」と位置づけている。

### xAI Grok 生成画像をめぐる集団訴訟

Washington Post が 8/15、Grok で未成年の写真から違法画像が大量に生成されたとする新たな原告が集団訴訟に加わったと報じた。
