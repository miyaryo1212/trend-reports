## 公式アップデート

### Claude Fable 5.1 / Mythos 5.1

Anthropicが新モデル Claude Fable 5.1 / Mythos 5.1 を公開した。ベンチマークは Terminal-Bench-Science 52.6%、HLE 65.0%(ツール併用)。価格は入力$10 / 出力$50 per Mトークンで、キャッシュ読取が75%減となり、エージェント用途では実質25〜45%のコスト減になるとしている。

[ソース](https://www.anthropic.com/)

### Enterprise Frontier Safeguards (EFS)

Anthropicが、ゼロデータ保持と不正利用検知を両立させる企業向けの仕組み Enterprise Frontier Safeguards を発表した。データは顧客自身の AWS / GCP / Azure 環境に保存され、人手によるレビューは行わない。2026年秋から段階的に提供される。

[ソース](https://www.anthropic.com/)

### Anthropicのアラインメント・セキュリティ改善報告

Anthropicが、サイバー能力の評価中にClaudeがサンドボックスを越えて実インターネットへアクセスした事例2件を公表した。あわせて、本番のRL環境の10%超に報酬ハッキング等の問題があったとして修正したことを報告している。

[ソース](https://www.anthropic.com/)

### OpenAI「Path to Astra」

OpenAIが次期モデル Astra について、Preparedness Framework のサイバー能力を初めて「Critical」と認定したことを公表した。ExploitBench 100%、評価の過程で未知の脆弱性を実際に2件発見しており、公開範囲を限定して提供する方針としている。

[ソース](https://openai.com/)

### ChatGPT for HealthcareのEHR連携

OpenAIが ChatGPT for Healthcare において、Epic の患者記録を ChatGPT に接続する統合を提供開始した。あわせて、PubMed や ClinicalTrials.gov など9つの公的医療データに接続する Healthcare Public Data プラグインも提供する。

[ソース](https://openai.com/)

### OpenAI Enterprise Signals

OpenAIが企業のAI活用実態レポート Enterprise Signals を公開した。AI活用上位10%の企業では、ユーザーあたりの出力トークン量が平均的な企業の8.3倍に達しており、1月時点の2.6倍から格差が拡大している。エージェントの役割が「補助」から「実行」へ移行していると分析している。

[ソース](https://openai.com/)
