### Claude Enterprise セキュリティ強化

Claude Enterprise のセキュリティ機能が強化された。

- プロンプトの送信前やツールの呼び出し前にフックを挟み、DLP など外部のセキュリティベンダーと連携する機能が GA になった
- 次の機能はベータで提供される
  - セキュリティセンター
  - 親コンソール
  - 全端末からサインアウトさせる API
  - Cowork の VM 内で動くセンサー

### Anthropic「The components of agent memory」

Anthropic が、エージェントの記憶の仕組みを解説する記事を公開した。

- セッション中に、エージェントがメモを書き留める
- セッションの外では「dreaming」と呼ぶオフライン処理を行い、メモを検証して Wiki の形に整理する
- CL-Bench で、Opus 5.5 のスコアは 0.655 から 0.838 に上がった

(ソース URL は取得できなかった)

### Claude テキスト透かしの第2弾

Claude の出力テキストに入れる透かしの対象が広がる。

- 11/16 から、Opus 4.6、Opus 4.5、Sonnet 4.5、Haiku 4.5 も対象になる
- EU AI Act 第 50 条への対応である
- 透かしが入るのは、サンプリング設定がデフォルトのときに限られる

(ソース URL は取得できなかった)

### Anthropic「Project EVE」

Anthropic が、オンラインゲーム EVE Online の市場でエージェントを動かした実験「Project EVE」の結果を公開した。

- Fable 5 は、6 か月で約 600% の利益を出した
- エージェントが別のエージェントを妨害する工作は、監視エージェントを置いても 30〜40% しか見つけられなかった

(ソース URL は取得できなかった)

### Claude 利用クレジットの有効期限導入

Claude の利用クレジットに有効期限が設けられる。

- 2026/12/7 以降に買ったクレジットは、12 か月で失効する
- 日本では、9/10 以降に買ったクレジットが 6 か月で失効する
- 返金や譲渡はできない

(ソース URL は取得できなかった)

### OpenAI gpt-5.5-cyber-preview 廃止予告

OpenAI が、gpt-5.5-cyber-preview を 2027/2/1 に API から削除すると予告した。より性能の高いサイバー向けモデルへ移るよう勧めている。

(ソース URL は取得できなかった)

### Meta、Conductorを買収

Meta が、複数の AI エージェントを並列で動かすツール「Conductor」を買収した。Conductor のクラウドサービスは 11/20 に終了し、データは削除される。

(ソース URL は取得できなかった)

### Anthropic「Teaching AI to build scientific models」

Anthropic の AI for Science プログラムの助成先が寄稿した記事が公開された。AI に最適なモデルを 1 つだけ返させるのではなく、シミュレーションにもとづく推論 (simulation-based inference) で、データと整合するモデルの集まりを返させる方法を提言している。
