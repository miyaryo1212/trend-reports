## 公式アップデート

### Claude Fable 5.1 のAPI仕様変更

Claude Fable 5.1 で API の互換性に関わる変更が入った。`tool_choice` の `any` / `tool` 指定が 400 エラーを返すようになり、thinking ブロックは生成したモデル以降でのみ再利用可能となる。キャッシュ読取は $0.25/MTok。

[ソース](https://docs.anthropic.com/)

### Claude APIのper-message effort (beta)

`messages` 配列の途中に `role: "system"` のメッセージを挿入することで、プロンプトキャッシュを保持したまま会話の途中で effort を変更できるようになった。

[ソース](https://docs.anthropic.com/)

### Claude APIのturn-scoped system messages (beta)

`clear_at: "next_user_message"` を指定すると、そのターンだけ有効なシステム指示を出せる。キャッシュと thinking ブロックのいずれも壊さない。

[ソース](https://docs.anthropic.com/)

### thinking.displayの"updates" (beta)

`thinking.display` に `"updates"` を指定すると、推論本文は隠したまま、ツール呼び出しの合間に出る短い進捗メッセージだけを text として受け取れる。

[ソース](https://docs.anthropic.com/)

### Claude Code 2.1.257 / 2.1.258

Fable 5.1 が既定の Fable モデルになった。auto mode に Containment Escape ルールが追加され、`timeFormat` / `timeZone` 設定が入り、macOS 12 での起動不具合が修正された。

[ソース](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### Codex CLI 0.152.0 / 0.152.1

Vim モードで `/` `?` による検索が使えるようになった。レート制限バナーから使用量確認・プラン管理へ遷移できるようになり、MCP ツール単位で `output_token_limit` を指定できる。

[ソース](https://github.com/openai/codex/releases)

### ChatGPT for iOS 1.2026.237

実行中タスク・未読・要返信を上位に表示する Priority ビューが追加された。Windows / Linux を含む全接続ホストで添付ファイルとキュー済みプロンプトが同期される。

[ソース](https://help.openai.com/)

### OpenAI APIのエラーコード細分化 (9/2)

急激な流量増は 429 `slow_down`、モデル過負荷は 503 `server_is_overloaded` として区別されるようになった。いずれも `Retry-After` が付与される。

[ソース](https://platform.openai.com/docs/guides/error-codes)

## コミュニティの反応

### Claude Fable 5.1 のAPI仕様変更

#### ポジティブ

> キャッシュ読取が $1 → $0.25/MTok に下がり、同じコードを繰り返し読む使い方が大幅に安くなった。最上位モデルが普段使いの値段に降りてきたという実感 — @araiguma2xx [出典](https://x.com/araiguma2xx/status/2095007024623018197)

#### ネガティブ

> tool_choice によるツール強制がエラーになり、thinking ブロックは生成モデル以降でしか再利用できず、過去履歴の編集で無効化される。会話履歴は追記式のみ推奨 — @ikioideok [出典](https://x.com/ikioideok/status/2094963226467508355)

> thinking ブロック生成前の履歴・system prompt・tools を変更するとエラーになる。思考の不正蒸留対策だが、自作ハーネス勢は履歴圧縮や reminder 差し込みまで注意が必要 — @connect24h [出典](https://x.com/connect24h/status/2094926674823639528)

#### Tips

> API 経由はキャッシュのデフォルトが5分（1時間に設定可）。放置するとキャッシュが効かずフル料金になるため、1時間以上空くケースは書き込み料金差も踏まえて使い分けるべき — @kinocodesunen [出典](https://x.com/kinocodesunen/status/2095101439014297899)

> キャッシュは1時間以上放置すると腐る。Claude Code のサブスクは1時間キャッシュだが、API 経由では明示指定しない限り5分でリセットされる — @nagataku_ai [出典](https://x.com/nagataku_ai/status/2095040672105697669)
