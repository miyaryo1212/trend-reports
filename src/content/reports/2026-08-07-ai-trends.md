## 公式アップデート

### GPT-5.6 Sol改善

8/6、ChatGPT の GPT-5.6 Sol が更新された。金融・医療・法律プロンプトを対象とした内部評価で、事実誤りを含む回答が GPT-5.5 Instant 比で 68% 減少。出力もより簡潔になった。

### ChatGPT無料枠でGPT-5.6 Luna無制限化

無料ユーザーおよび Go ユーザーのデフォルトモデルが GPT-5.6 Luna となり、テキストチャットが無制限になった。あわせて、より深く考えさせるための「Think」ボタンが追加された。

### ChatGPT推論スライダー追加

Plus / Pro ユーザー向けに、回答ごとの推論量を調整するスライダーが Web・モバイル・デスクトップに導入された。

### Meta Muse Spark 1.2公開

8/5、Meta がコーディング特化モデル Muse Spark 1.2 を公開した。Terminal-Bench 2.1 で 82.9%（1.1 は 76.2%）、DeepSWE v1.1 で 59.3%。コンテキスト長は約105万トークン。

### Meta Muse Code ベータ公開

Meta 初のターミナル型コーディングエージェント Muse Code がベータ公開された。Muse Spark 1.2 で駆動し、並列サブエージェント、worktree による作業分離、クラッシュ耐性のあるイベントログを備える。

### Muse Spark 1.2 contributorティア

学習データの提供に同意すると、入力 $0.10 / 出力 $0.20 で Muse Spark 1.2 を利用できる contributor ティアが用意された。標準価格（入力 $1.25 / 出力 $4.25）から大幅な割引となる一方、60 RPM のレート制限がかかる。
