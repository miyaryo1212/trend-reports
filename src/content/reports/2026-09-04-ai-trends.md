### GPT-6 Astra 発表

OpenAI が新世代フラッグシップモデル GPT-6 Astra を発表した。同社は「最も知的かつ最もアラインされたモデル」と位置づけ、computer use・コーディング・サイバーセキュリティ・科学の各領域で state-of-the-art の能力を主張している。

[ソース](https://openai.com/index/gpt-6-astra)

### GPT-6 Astra のCriticalリスク認定

同時公開された Safety overview によると、GPT-6 Astra は同社が広く展開したモデルとして最も高性能であり、Preparedness Framework においてサイバーセキュリティ能力が初めて **Critical** レベルに到達した最初のモデルとなった。

### Astra導入事例の実測公開 (Playco / Legora)

発表と合わせて、実運用での測定値を含む導入事例が2件公開された。

- **Playco**: 1つのグレーボックス基盤から3種類のテーマ別ゲームプロトタイプを構築し、従来モデル比で手戻り(manual fixes)が50%減少。
- **Legora**: 財務諸表レビューのワークフローで41文書を数分でレビューし、仕込まれた4件の誤りをすべて検出。性能は約40%改善。

[ソース (Playco)](https://openai.com/index/playco-game-prototyping-with-astra) / [ソース (Legora)](https://openai.com/index/legora-financial-statement-review-with-astra)

### Claude Code v2.1.259

組織運用・無人実行まわりの整備が中心。

- `managedMcpServers` 管理設定を追加。組織が HTTP/SSE の MCP サーバーを全ユーザーへ配布できる (エントリ形式は `.mcp.json` と同じ。コマンド実行を指定するエントリはスキップされる)。
- `--permission-prompts none` を追加。無人ヘッドレスホスト向けに、プロンプトが出る操作を自動的に拒否する (auto mode を含む権限モードの判断自体は維持)。
- `glab mr create/merge/close/reopen/note/update` を認識し、GitLab の MR が `MR !N` として表示されるように。
- `claude plugin validate` に `--json` を追加。
- 複数セッションが互いの `~/.claude.json` 変更を無言で巻き戻す問題を修正。ワークスペース信頼のリセットや MCP/プロジェクト状態の消失が起きなくなった。
- Bash の `Read()` 拒否ルールが、オプション値として渡されたファイル (`--ignore-revs-file=.env`、`-f.env`、`@file`)、`git diff`/`git grep` のファイル引数、`cd DIR && cat FILE` の複合コマンドをカバーしていなかった問題を修正。
- 管理設定ファイル・drop-in・MDM plist・HKLM 値のいずれかがパースできない場合、管理設定が無言で未適用になるのをやめ、起動を拒否して原因を明示するように変更。

[ソース](https://github.com/anthropics/claude-code/releases/tag/v2.1.259)

### Codex CLI 0.153.0

- Vim モードが `u` による undo と `Ctrl+R` による redo に対応。貼り付け内容や添付を含む下書き全体が保持される。
- plugin CLI がリモートマーケットプレイスからのプラグイン一覧取得・インストール・削除に対応。
- `tui.auto_recap = false` で自動 recap を無効化しつつ、手動 `/recap` は維持できる。
- TUI 履歴が完全なパッチ、バックグラウンドターミナルへの入力、個々の完了コマンドを表示。
- Plus / Team ユーザーに対し、約5時間の利用枠の残りが半分を切った時点で早期警告。
- 外部 app-server 接続断からの TUI セッション再接続、Guardian レビュー履歴の compaction/再起動/fork 越しの保持、MCP ツール承認のアカウント単位スコープ化などの修正。

なお、alpha 版 0.154.0-alpha.1 も同日公開されている。

[ソース](https://github.com/openai/codex/releases/tag/rust-v0.153.0)
