### 物理世界のエンジニアリング加速 (Accelerating engineering for the physical world)

OpenAI は、ChatGPT と Codex を使って CAD、PCB 設計、シミュレーションといったハードウェア系のワークフローを速める事例を公開しました。

### 次期社内セキュリティスプリント

OpenAI は Cathedral Systems と組み、AI を使って自社の防御をテスト・強化する社内セキュリティスプリントを準備していることを明らかにしました。

### Cisco事例 (Cisco defends at machine speed)

Cisco が自社のネットワークインテリジェンスと OpenAI のモデルを組み合わせ、企業向けセキュリティを強化している事例が公開されました。

### Heimstaden事例

欧州の不動産会社 Heimstaden が ChatGPT Enterprise と Codex を使って物件管理を変え、コストを削減した事例が公開されました。

### Grid Protectors Program

OpenAI は「Grid Protectors Program」を発表しました。電力会社と連携し、今後建設する計算拠点の周辺で電力網を安定させるとともに、消費者の電気料金を守ることを目的としています。
