### Claude Code v2.1.260 の権限ルール欠陥修正

権限まわりで、指定したはずの制限が実際には効いていなかった不具合がまとめて修正された。

- 括弧を含むパスを持つ `Edit` / `Write` / `Read` の権限ルールが、無効として破棄されたり Bash サンドボックスから無視されたりし、**「read-only」に指定したフォルダが書き込み可能なままになっていた**問題を修正。
- コンパイルできないパターン (閉じていない `[` など) を含むファイル権限ルールが1つあると、すべてのファイル編集が `Invalid regular expression` で失敗していた問題を修正。該当する deny ルールは、綴られたリテラルパスを保護する扱いになった。
- `REPORTTIME` / `REPORTMEMORY` / `DIRSTACKSIZE` への代入にコマンド置換を隠した zsh コマンドを、Bash の権限チェックが自動承認していた問題を修正。これらは承認プロンプトが出るようになった。
- `permissions.blockReadsOutsideWorkingDirectories` が macOS で、サンドボックス化された git からユーザーの git config を隠し、worktree 分離されたサブエージェントから自身のチェックアウトを隠していた問題を修正。
- 管理設定が、以前の `/login` で残った API キーを併せ持つ claude.ai Enterprise / Team ユーザーに対して読み込まれなかった問題を修正。`/status` はサインイン中のアカウントと設定済み API キーの双方を有効であるかのように列挙していたが、使われていない方を明示するようになった。

[ソース](https://github.com/anthropics/claude-code/releases/tag/v2.1.260)

### Claude Fable 5.1 まわりのツール整備

v2.1.260 では Fable 5.1 に関する取りこぼしが3件修正された。

- Fable 5.1 でツール結果の後に付いたコンテキストがプロンプトキャッシュの対象から漏れており、ツール呼び出しのたびに未キャッシュ入力として再送されていた問題を修正。
- `/model` ピッカーが、利用可能な組織に対しても Fable 5.1 を表示していなかった問題を修正 (それまでは `/model claude-fable-5-1` と入力した場合のみ受け付けられていた)。
- `model: fable` のエージェントが `ANTHROPIC_DEFAULT_FABLE_MODEL` のピンに付いた `[1m]` タグを無視し、無言で 200K コンテキストで動作していた問題を修正。

[ソース](https://github.com/anthropics/claude-code/releases/tag/v2.1.260)

### エージェントCLIの無人運用対応

v2.1.261 では、長時間・遠隔での実行に効く設定追加と安定化修正が入った。

- `bashOutputMaxChars` / `taskOutputMaxChars` を追加。コマンドとバックグラウンドタスクの出力が、ファイルに退避される前にインラインで Claude に渡る量を **最大128K文字** まで引き上げられる。
- `--append-subagent-system-prompt-file` を追加。コマンドラインに渡すには大きすぎるサブエージェント用システムプロンプトをファイルから読み込める。
- Remote Control 系の修正: 電話・ブラウザ・claude.ai アプリがターミナルセッションに接続した際の権限モード表示の陳腐化、ターンを停止した後もセッションが実行中に見え続ける (スピナーとStopボタンが残る) 問題、TLS 検査を行う企業プロキシ配下の Windows で受信イベントストリームが失敗する問題、`/teleport` で取得したセッションが接続先セッションにアップロードされる問題など。
- SDK / クラウドセッションが、最初のプロンプト直後・ターン開始前に送られた Stop や割り込みを無視して最後まで走り切っていた問題を修正。
- バックグラウンドエージェントが再開できないとき、その起床処理がタイトループでリトライされ CPU 使用率が高止まりする問題を修正。

[ソース](https://github.com/anthropics/claude-code/releases/tag/v2.1.261)
