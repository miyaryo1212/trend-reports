### Gemini Desktop の「Full Access」権限

デスクトップ上の任意のファイル読み書き・アプリ操作・ネットワーク通信を、都度確認なしで許可する設定が確認された。購入や法的同意を伴う操作については引き続き承認が必要。

### Cactus Compute「Whistle」

16.9MB の単一ファイルで動く音声認識モデル。CPU のみで動作し、Whisper base 比で9分の1のサイズ・6倍速、first token 11ms、7言語対応。

### Bilibili Index-Translate-35B-A3B-preview

総パラメータ35B・アクティブ3B の MoE 翻訳モデルを Apache 2.0 で公開。150言語・262k コンテキストに対応する。

### Anthropic Transparency Hub 更新

Claude Opus 5.5 / Sonnet 5.5 のモデルレポートを公開。Sonnet 5.5 は政治的中立性の API スコアが 86.2% から 97.9% に改善したとしている。

### Meta Muse Spark による数学論文6本公開

Muse Spark 1.1 / 1.2 を meta.ai の通常チャットで使い、未解決問題5件を解決したと主張。レビュワーからは「半数は既に他者が解決済み」との反論が出ている。

### Volantis が8,800万ドルのシリーズA

マイクロVCSEL光接続でGPUに最大220個のメモリチップを束ねる推論アーキテクチャ「A-1」を開発。20兆パラメータ級・1ユーザー1万tok/秒を目標とし、2027年の提供を予定する。

### Jay Clayton が米「AI czar」に指名される見通し

DNI (国家情報長官) を兼任したまま政権横断のAI政策を統括する。David Sacks に続く2人目となる。
