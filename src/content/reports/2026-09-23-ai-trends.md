### Claude Opus 5.5 公開 (Anthropic)

Anthropic が 9月22日に Claude Opus 5.5 を公開した。Terminal-Bench 4.0 のスコアは 66.4% (Opus 5 は 52.3%)、出力速度は約30%高速化。料金は入力 $4 / 出力 $20 per 1M トークンで、従来比およそ40%の値下げとなる。AWS / GCP / Azure でも即日提供が開始された。

### GPT-6 Sol / Luna 公開 (OpenAI)

OpenAI が 9月22日に GPT-6 Sol と GPT-6 Luna を公開した。料金は Sol が入力 $2 / 出力 $10、Luna が入力 $0.10 / 出力 $0.50 で、GPT-5.6 比でおよそ50%の値下げ。ChatGPT Work と Codex で提供が始まり、Free / Go プランでも Luna が利用できる。

### GPT-6ファミリーのプロンプトキャッシュ改善 (OpenAI)

同じく 9月22日、OpenAI が GPT-6 ファミリー向けにプロンプトキャッシュの改善を発表した。キャッシュの有効期間を30分に拡大し、キャッシュ入力トークンは最大90%割引。あわせて専用ダッシュボード、診断機能、プリウォーム、明示的なキャッシュ区切りの指定が追加された。

### OpenAI「第三者評価の優先領域と原則」公開

OpenAI が 9月22日、第三者評価に関する優先領域と原則を公開した。学習段階での安全性評価を外部団体に開放する方針を示し、4つの評価優先領域と7つの原則を提示している。

### Grok 4.7 公開 (xAI)

xAI が 9月21日に Grok 4.7 を公開した。パラメータ数は2.1兆 (Grok 4.6 比 +40%)、コンテキスト長は50万トークン。料金は入力 $2 / 出力 $6 で据え置き。補助的な学習データとして SpaceX の衛星テレメトリや製造記録を使用したとされる。

### Xiaomi MiMo-V2.6 シリーズ公開

Xiaomi が 9月21日、MiMo-V2.6 Pro (総1.02T / アクティブ42B、1Mコンテキスト) と MiMo-V2.6 Flash (総309B / アクティブ15B) を MIT ライセンスで Hugging Face に公開した。オムニモーダル対応で、Artificial Analysis Intelligence Index は 46.32。

### Intrinsic Core 公開 (Alphabet傘下Intrinsic)

Alphabet 傘下の Intrinsic が、トロントで開催された ROSCon 2026 で ROS 互換のロボティクス開発環境「Intrinsic Core」を Apache 2.0 ライセンスで公開した。
