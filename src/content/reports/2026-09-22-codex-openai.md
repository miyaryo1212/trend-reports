## 公式アップデート

### Codex CLI 0.157.0-alpha.1

0.156 系のアルファが進行中のまま、新たに 0.157 系のアルファラインが分岐した (9/21)。リリースノートは「Release 0.157.0-alpha.1」の自動生成表記のみで、変更内容は公開されていない。0.156 系はいまだ安定版に到達していない。

[ソース](https://github.com/openai/codex/releases/tag/rust-v0.157.0-alpha.1)

### Codex CLI 0.156.0-alpha.11〜alpha.17

0.156.0 のアルファ系列が 9/20〜9/21 の 2 日間で alpha.11 から alpha.17 まで 7 本連続で公開された。いずれもリリースノートは自動生成表記のみで内容は非公開。alpha.15 / alpha.17 は個人アカウント (jif-oai)、それ以外は github-actions[bot] による公開。

[ソース](https://github.com/openai/codex/releases)

### OpenAI Academy 学習パス拡充

OpenAI Academy に学習パスが 4 本追加され、開発者向けの「Build with AI」(Codex / API を扱う 8 コース構成) が含まれる。あわせて修了バッジ制が導入された。

[ソース](https://academy.openai.com/)

### 数学AI諮問グループ設置

OpenAI が Timothy Gowers、Edward Witten ら 9 名からなる独立の数学 AI 諮問グループを設置した。内部モデルが未解決問題 100 件超を解決したとする主張に対し数学界から批判が出ていたことへの対応。

[ソース](https://openai.com/news/)
