### Meta「Muse Wonder / Muse Wonder Full」発表

Meta Superintelligence Labs が初のフロンティアモデル「Muse Wonder」と上位版「Muse Wonder Full」を発表した（10/12）。

- Claude Fable 5.1 や GPT-6 Astra 相当の性能を主張
- 「Active Memory」機能により MemoryBench で首位
- API 価格は入力 $4 / 出力 $20（100万トークンあたり）
- Muse Wonder Full は Muse Code 加入者限定で、API 提供なし

### 「The X Subscription」でGrok・Cursor・X Premiumを統合

SpaceXAI が Grok、Cursor、X Premium のプランを「The X Subscription」として一本化した（10/12）。

- 無料〜Ultra（$200/月）の5段階プランに再編
- Grok モデルの利用量を Grok アプリ・X・Cursor の間で共有

### Anthropic、蒸留攻撃への防御強化を発表

Anthropic がモデル蒸留攻撃への防御強化策を発表した（10/12）。

- 「preserved thinking」での推論ブロック持ち出しを防止
- 誤検知率 0.1% 未満の分類器を導入
- 利用制限および BAN の3本柱で、攻撃者が取得できる推論トークンを 90〜99% 削減
- ブロックされたリクエストも課金対象

### Anthropic、Gitを捨て自社製ソース管理「Scion」に移行

Anthropic が社内のソース管理を Git から自社製 VCS「Scion」へ移行したことを公開した（10/13）。

- 1日3万件超のマージに対応する、エージェント時代向けの設計
- サーバーサイドでのコミット／マージ、仮想チェックアウトを採用
- インフラコストを 200 分の 1 に、CI 容量を 25% 改善
- 7人チームが5か月で構築・移行

### Character.AI がChapter 11申請、Disneyが2,000万ドルで資産買収へ

Character.AI が Chapter 11（米連邦破産法第11章）を申請した（10/12-13）。

- Google との 27 億ドル契約から2年で破綻
- Disney が 2,000 万ドルでスタルキングホース入札者となり、IP の非独占永久ライセンスを取得見込み
- 売却完了は 11〜12 月の見込み。サービスは継続

### Artificial Analysisが「FrontierCode 1.1」リーダーボード公開

Artificial Analysis が Cognition 製のメンテナ採点型コーディング評価「FrontierCode 1.1」のリーダーボードを公開した（10/13）。

| モデル | スコア |
| --- | --- |
| Claude Opus 5.5 | 52.2% |
| GPT-6.1 Sol | 49.1% |
| Claude Fable 5.1 | 49.0% |

最上位モデルでも4割超のタスクが未解決。

### OpenAI、Higgsfield事例でAI動画を1分→10分超に

OpenAI が Higgsfield の事例を公開した（10/13）。GPT-6 Astra・GPT-Image-2.5・GPT-Live を組み合わせ、AI 動画の長さを1分から10分超へ拡張した長尺動画生成と、音声による映像制作の事例を紹介している。
