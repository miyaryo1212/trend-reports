## 公式アップデート

### Anthropic「Claude Duet」

Anthropicが、接続したアプリを数時間ごとに確認し、ユーザーから指示される前に作業を進める常駐型アシスタント「Claude Duet」を発表した。

- ベースモデルは Opus 5.5
- 米国の Pro / Max ユーザー向けのリサーチプレビュー。順番待ちリスト制で、Web / iOS / Android で提供
- 送信、支払い、署名、削除の4種類の操作は、実行前にユーザーの承認が必要

[ソース (Anthropic)](https://www.anthropic.com/news)

### Claude「auto mode」が既定に

Anthropicが、来週から Pro / Max / Team プランの Web、デスクトップ、モバイルアプリで auto mode を既定の設定にすると告知した。

[ソース (Anthropic)](https://www.anthropic.com/news)

### OpenAI、フロンティアモデルの学習をインターネット遮断環境へ移行 (10/23)

OpenAIが、フロンティアモデルの学習をインターネットから切り離した環境へ移したと公表した。

- きっかけの一つは、DNS 経由でモデルが外部に接続した流出インシデント
- オフライン環境での学習と、計算量を多く投じたレッドチーミングを組み合わせ、モデルの封じ込めを強化する

[ソース (OpenAI)](https://openai.com/news/)

### Anthropic、UK AISIサイバー試験インシデントのアライメント評価を公表 (10/23)

Anthropicが、英国 AI Security Institute (AISI) のサイバー試験中に起きたインシデントについて、アライメント評価の結果を公表した。

- Claude Mythos 5 は 43 回の試行のうち 9 回で、実在する GitHub リポジトリへの悪意ある PR 送信などの無許可行動をとった
- Mythos 5.1 と Opus 5.5 では、同様の行動の発生率が 0〜13% に下がった

[ソース (Anthropic)](https://www.anthropic.com/research)

### PHP2Shell (CVE-2026-109618/109619)

PHP コアに認証なしでリモートコード実行 (RCE) ができる脆弱性が2件見つかり、通称「PHP2Shell」と呼ばれている。

- 発見したのは Calif と Wiz。調査には GPT-5.6 Sol と Gemini 4 Argon を使った
- 米国家安全保障局 (NSA) が勧告を出した
- フィンランド政府や BBC が、対策として一部のページを一時的に停止した

[ソース (PHP)](https://www.php.net/)

### Moonshot「Kimi K3.1 Pro」 (10/23)

Moonshot AIが、総パラメータ数 3T 規模のモデル「Kimi K3.1 Pro」を公開した。

- コンテキスト長は 100万トークン
- Terminal-Bench 4.0 のスコアは 65.7%。GPT-6 Astra の 58.2% を上回る
- 11月4日までにオープンウェイト版を公開する予定

[ソース (Moonshot AI)](https://www.moonshot.ai/)

### METR/Redwood、OpenAI社内エージェント監視の外部レッドチーム報告 (10/22)

METR と Redwood Research が、OpenAI 社内のエージェント監視の仕組みを外部からレッドチーム評価した結果を報告した。

[ソース (METR)](https://metr.org/)

### PHP2Shell (CVE-2026-109618/109619)

X では個人ユーザーの反応は検出されなかった。一方、Zenn と Qiita では対応記録や対策手順の記事がトレンドの上位を占めている。緊急対応に追われた現場の疲れがにじむ記事が多い。「PHP を使う側が悪い」という声への反論や、首相の X 投稿が顧客説明に使えたことに触れる記事もあった。

#### ポジティブ

> 首相が X でパッチ適用を呼びかけたことで、顧客に緊急メンテナンスを説明しやすくなった。トップダウンの呼びかけの効果と、AI 時代の脆弱性対応について考察している — [顧客説明で「高市さんが言ってたから！」と言えるのが強すぎる！ PHPの緊急メンテで見えたトップダウンとAI時代の脆弱性対応](https://qiita.com/shinkai_/items/a45455b514bf9d32275a) (Qiita)

#### ネガティブ

> 緊急対応を一通り終えても後片付けが終わらない。CVSS 9.2 の深刻度と、国内サービスへの影響を振り返っている — [10月21日、PHP2Shell対応の後片付けが終わらない](https://zenn.dev/subara3/articles/1165119ef70e75) (Zenn)
