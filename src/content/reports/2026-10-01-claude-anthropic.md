## 公式アップデート

### Claude Code v2.1.286

2026-09-30 公開。新モデルや大きな機能追加はなく、修正と細かな改善が中心のリリースです。

- **権限プロンプトの件数表示**。権限リクエストが複数重なった際に「2 of 5」のような件数が表示される。
- **シークレット秘匿の強化**。ログ・トランスクリプトでのマスキング漏れが複数修正された。記号 (`)`、引用符、`]`、`&`、2つめの `@`) を含む URL パスワード、`/` をまたいで `[::1]` のようなブラケット付きホストに達する ssh URL のパスワード、ゼロ幅スペースなど不可視文字を含むキー名のシークレット、パーセントエンコードされた Bearer トークンが対象。`/feedback` が保存する zip 内のトランスクリプトが、秘匿処理後に不正な JSON 行になる問題も修正された。MCP のエラーメッセージで「Bearer」「Basic」がキー名より前に来た場合に値が表示される問題も直った。
- **`--bare` の挙動変更**。コマンドラインで指定した MCP サーバーのみを接続し、モデルにシステムリマインダーを送らず、バックグラウンドタスクも開始しない。`--bare` 下では、タイムアウトに達したシェルコマンドはバックグラウンドに移らず停止する。
- **API リトライ予算の統合**。失敗した API リクエストのリトライ方法が変更され、1つのモデル呼び出し全体で1つの上限を共有する。既定のリトライ設定では、失敗する呼び出しが送るリクエストは最大14件。
- **モデル拒否時の自動フォールバック**。既定モデルやモデルエイリアスの解決先を Anthropic API が拒否した場合、同ティアの旧モデルで1回だけリトライする。あわせて、拒否や `--fallback-model` のリトライで、フォールバック先が fast で動けない場合に失敗していた問題が修正され、標準速度で実行されるようになった (対話セッションでは一度だけ通知が出る)。
- **プラグイン依存のインストール制限**。プラグインのインストールで、git リポジトリやフォルダを指す npm ソースを拒否するようになった。プラグインの依存はレジストリパッケージからのみインストールされる。
- **バックグラウンドエージェント表示中の誤操作防止**。バックグラウンドエージェントやチームメイトのトランスクリプトを表示中に `/compact`・`/clear`・`/rewind` を入力すると、これまでは黙ってメインの会話に作用していた。対象を明示するダイアログで確認するようになった。
- **`verify` スキルのコミット前実行ガイダンス**。プロジェクトまたはユーザーのスキルに `verify` という名前のものがある場合、コミット直前にそれを実行するよう Claude に指示される (ドキュメントのみ・テストのみのコミットは除く)。
- **フルスクリーンのリスト操作改善**。リストの「N more」行がマウスに対応し、クリックでその端までジャンプできる (ホバー・押下状態あり)。スクロールバーは「N more」行の出入りで位置がずれなくなり、クリックまたは長押しでスクロールできる ↑/↓ ボタンが付いた。オーバーフロー行の表記は「N more above」「N more below」から「↑ N more」「↓ N more」に変更。
- **[VS Code] ブックマーク**を追加。Claude の応答を保存し、Bookmarks サイドパネルに表示して参照し続けられる。
- **[VS Code] 質問カードの会話への記録とオプションプレビュー**。質問カードに回答すると Questions 行が残り、各質問と自分の選択が表示される。また、ハイライト中の選択肢のモックアップやスニペットが、選択肢の横または下にプレビュー表示される。
- **[VS Code] Stop/Escape の挙動変更**。現在のターンのみを終了するようになり、バックグラウンドエージェントは動き続ける。停止はエージェントマップから個別に行う。
- **[Cloud sessions] 起動しなかったルーティン実行の表示修正**。クラウドセッションが開始されなかったルーティン実行が、Runs ペイン・ルーティンのページ・サイドバーで Succeeded と表示されていた。Failed と表示されるようになった。
- **[Claude Tag] スペンド上限ページの Add channel ボタン**を追加。管理設定の Claude Tag スペンド上限ページで、チャネル ID や Slack リンクからプライベートチャネルを含む任意のチャネルに上限を設定できる。
