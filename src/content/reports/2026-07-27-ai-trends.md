## 公式アップデート

### ChatGPT Health 全米一般提供開始

OpenAI が ChatGPT Health を 7/23〜24 にかけて、18歳以上の全米ユーザー・全プランへ Web / iOS で開放した。患者ポータルや Apple Health などの医療・健康データを連携し、自分の検査結果を基に質問できる専用スペースを提供する。

[OpenAI](https://openai.com)

### Claude 5 世代（Opus 5）への適応

モデル更新に伴い、既存のルールやプロンプト運用をどう合わせ直すかという実践知の共有が出てきた。

#### Tips

> Claude Code を Opus 5 に切り替えた直後から応答が散文的になり「思考が浅くなった」と感じた原因を、モデルや rules の劣化ではなく Claude 5 世代で配布される本体 system prompt の変化に切り分け、旧来の rules を新しい前提へ直すまでを記録。 — @Yuichi Uemura [Zenn](https://zenn.dev/u1/articles/claude5-rules-collapse-and-fix)

### コーディングエージェントの活用と境界設計

エージェントを本番や日常運用に載せる際、権限・機密・自動実行の境界をどう引くかへ関心が移っている。

#### 実践

> ターミナルを自作したところ GitHub のコミットが毎日500を超えるようになり、生産性が「バグった」体験を記録。ターミナル前提の開発フローを突き詰めた事例。 — @Isamu [Zenn](https://zenn.dev/singularity/articles/diy-terminal-500-commits)

> ローカル LLM（Ollama）を Codex CLI や Claude Code から駆動する構成の手順をまとめ、クラウド API に依存しないエージェント運用を検証。 — @ichiken26 [Qiita](https://qiita.com/ichiken26/items/5bfc4baad0c487475355)

#### 注意

> Cursor や Claude Code などで使う Agent Skills をチームや本番に載せる前に、権限の広がり・機密情報の混入・意図しない自動実行を防ぐための境界チェック観点を初心者向けに整理。 — @YushiYamamoto [Qiita](https://qiita.com/YushiYamamoto/items/e1dc7a8dbb13b924dd66)

### AI時代の開発プロセスと品質・成果の捉え方

実装が速くなった分、ボトルネックが開発プロセスや品質・評価の側へ移っているという議論が続く。

#### 考察

> AI駆動開発で実装の自動化が進んだ結果、ボトルネックは「誰が・いつ・何を決め・何に責任を持ち・どの順でリリースするか」という開発プロセスへ移ったとし、ドメイン駆動「設計」から「開発プロセス」の時代へと論じる。 — @meijin [Zenn](https://zenn.dev/manalink_dev/articles/domain-driven-development-process)

> AIでコードを書く速度が上がる中、エンジニアリングマネージャーが外部品質をどう可視化し、現場と経営をつなぐ形にするかを実践的に整理。 — @Yoshiki Iida [Zenn](https://zenn.dev/loglass/articles/ef099b123153cf)

### AIによる分析・生成の限界と検証

生成AIを分析や執筆に使ってみて、その有効性や限界を検証する報告が並んだ。

#### 考察

> 東証20年分のデータを生成AI（fable5 と codex）に与え、窓埋めや三尊などの定番テクニカルパターンに優位性があるかを総当たりで検証した実験を起点に、クオンツがテクニカル分析を寄与度分解の中でどう見ているかを解説。 — @Tomoya Kitayama [Zenn](https://zenn.dev/gamella/articles/7e1af53f19d94d)

> AIエージェントがあれば技術書はすぐ書けると思ったが実際は無理だった、という単著執筆の実体験。生成AI×システム開発というテーマでも、書籍化には人手の作り込みが要ると振り返る。 — @watany [Qiita](https://qiita.com/watany/items/11358e8e8966d5e48a09)

#### 注意

> スライドをAIで作り直したら、かえって分かりにくくなった経験から「ひとことで、言え」という要約の重要性を説く。AIによる自動生成が常に改善とは限らないという注意喚起。 — @WdknWdkn [Qiita](https://qiita.com/WdknWdkn/items/ba228da40b5d2fd1b612)
