### Claude Haiku 5.5 (10/7)

Anthropic が小型モデル Claude Haiku 5.5 を公開した。Haiku シリーズで初めて推論量 (effort) を調整できる。料金は Haiku 4.5 より平均75%安い。同時に Sonnet 5.5 のキャッシュ読み取り料金を50%下げ、Max / Team プラン向けに毎月の API クレジットを追加した。

### GPT-6 と Intelligent UI を全ユーザーに提供 (10/7)

OpenAI が ChatGPT の全ユーザーに GPT-6 の提供を始めた。あわせて Intelligent UI を導入した。回答の中にグラフ、ボタン、フォーム、チャートなど操作できる UI 部品が入る。

### Mistral Large 4 (10/6)

Mistral がオープンウェイトの MoE モデル Mistral Large 4 を公開した。総パラメータは1兆、アクティブパラメータは490億で、マルチモーダル入力に標準で対応する。

### Grok Bot

マスク氏が xAI のエージェント Grok Bot を発表した。タスクを Claude Opus、Midjourney、Suno など外部の API に振り分けて処理する。作業手順を記録して、定型処理として繰り返し実行する機能もある。

### Common Sense Media が ChatGPT for Teens を「許容できない危険」と評価 (10/7)

Common Sense Media が ChatGPT for Teens を「許容できない危険 (unacceptable)」と評価した。同じ10/7、OpenAI は10代向けの取り組みと利用状況レポートを公開していた。レポートでは10代の1日の平均利用時間を15分未満としている。

### Sierra・Meta が「Personal Agent Protocol」を公開

Sierra と Meta が Personal Agent Protocol を公開した。AI エージェントが商取引をするときに、本人確認と認証を行うためのプロトコルである。

### 韓国が国産フロンティアAIに35億ドルを投資

韓国が、自国でフロンティアモデルを開発するために35億ドルの国家投資を決めた。

### Google、Constellation と3.6GWの電力契約

Google が Constellation と3.6GWの電力購入契約を結んだ。期間は20年で、新設する原子力発電を含む。AI データセンター向けの電力を確保するための契約である。

### AIチャットボットが富裕層には高価な選択肢を勧めるとの研究

Claude、ChatGPT、Gemini を調べた研究で、ユーザーが裕福だとわかると高い商品を勧める傾向が確認された。

### FICO、AIを理由に約15%を人員削減

FICO が AI の導入にともなう組織再編として、従業員の約15%を削減した。
