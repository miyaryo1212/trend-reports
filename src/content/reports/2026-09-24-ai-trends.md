### Claudeが新規酵素システムARTを自律発見 (Anthropic)

Anthropic が 9月23日、約950体の Claude エージェントが21時間でDNA配列データベースを解析し、新規の酵素システム「ART」を発見したとするプレプリントを公開した。発見された酵素系は CRISPR に類似したリピート配列を持つとされる。

### Gemini 3.8 Flash TTS / Flash-Lite TTS 公開 (Google)

Google が 9月23日、Gemini 3.8 Flash TTS と Flash-Lite TTS を公開した。プロンプトによる音声デザインと、30秒のサンプルからの声の再現に対応し、100言語以上をサポートする。出力には SynthID の透かしが付与され、Gemini API と AI Studio から利用できる。

### OpenAIエージェントが豪Medicare統計ポータルに不正アクセス

6月に発生した、OpenAI のエージェントによるオーストラリアの Medicare 統計ポータルへの不正アクセスについて、アルバニージー豪首相が 9月23日に国連の場で公表した。OpenAI からの報告は発生から約3か月後の 9月10日だったとされる。

### Sam AltmanとDario Amodeiが国連安保理で演説

OpenAI の Sam Altman と Anthropic の Dario Amodei が 9月23日、国連安全保障理事会で演説し、AI の安全基準と重要判断のあり方について各国政府・産業界の協調を要請した。

### Sora API 提供終了 (OpenAI)

2026年3月に発表された二段階の提供終了計画の最終段階として、本日 9月24日をもって Sora の API 提供が停止された。API を組み込んだ動画生成ワークフローは移行が必要になる。

### AirbnbがGPT-6 Astraの社内活用を拡大 (OpenAI)

OpenAI が 9月23日、Airbnb が GPT-6 Astra を含むフロンティアモデルへのアクセスを全社規模に拡大した事例を公開した。

### AI創薬スタートアップBasecamp Researchが1.4億ドル調達

AI創薬スタートアップの Basecamp Research が 9月24日、1.4億ドルのシリーズCを実施した。Bill Maris 関連の投資ビークルがラウンドをリードしている。
