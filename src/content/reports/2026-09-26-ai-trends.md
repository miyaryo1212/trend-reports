### Claude Code の権限・メモリ運用

エージェント運用の「地味だが効く」ノウハウ系が複数ランクイン。

#### ネガティブ

> `permissions.deny` に書いたルールが書いたとおりに効かないことがある。2026-09-11 から 09-24 の2週間で権限まわりの修正が7つの版に出たが、7つの形で測った結果、最新版でもまだ4つ残っている。 — suwa_nobu [Claude Code の拒否ルールを7つの形で測った。最新版でまだ4つ残っている](https://qiita.com/suwa_nobu/items/d21ff35b9329eecc6143)

#### Tips

> `permissions.allow` に書いたルールが効かず、同じルールを `--allowedTools` で渡すと効く現象を56回測定。分かれ目は「そのフォルダを信頼したかどうか」だった。 — suwa_nobu [許可ルールを settings.json に書いても効かなかった。分かれ目はフォルダを信頼したかどうか](https://qiita.com/suwa_nobu/items/92d4de34077b9ae02fca)

> 自動メモリは気づかないうちに溜まる。人間が CLAUDE.md や .claude/rules に整理したものはよいが、それ以外は定期的に大掃除したほうがよい。 — nekolas (ログラス) [Claude Codeで定期的にやっておきたい MEMORY.md の大掃除](https://zenn.dev/loglass/articles/f69996279763ab)

> 指示していないのに新しいライブラリを入れて実装を進めることがある。サプライチェーン攻撃も踏まえ、依存の追加・更新の前に調査と人間の確認を挟む Hook を用意した。 — a.kobayashi (スプリックス) [Claude Codeによる依存追加・更新に「調べてからユーザに聞いて」を挟むHookの紹介](https://zenn.dev/sprix_it/articles/f3ef77c1d46554)

> `/usage` を何度も打って週末まで持つか暗算する代わりに、週間リミットが「いつ尽きるか」を予測する macOS ウィジェットを作った。 — akito8639 [Claude Code の週間リミット、気づいたら尽きてない？ →「いつ尽きるか」を予測する macOS ウィジェットを作った](https://qiita.com/akito8639/items/3d8f61c33da566662d0d)
