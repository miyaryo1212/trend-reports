## 公式アップデート

### Codex Security 研究プレビュー公開

OpenAI が、これまで Aardvark として研究プレビューされていた AppSec エージェントを **Codex Security** に改称し、Codex web 上で公開した。

- 対象プラン: ChatGPT Pro / Enterprise / Business / Edu
- 公開から1か月間は無料

[ソース](https://openai.com/news/)

### Codex Security が SAST レポートを起点にしない理由

OpenAI が技術記事で、Codex Security の設計判断を解説した。既存の SAST (静的解析) レポートを出発点にせず、**脅威モデルの構築と実行による検証を先に置く**構成を採っている。

公表されている実績値は以下の2点。

- ノイズを 84% 削減
- 誤検知を 50% 超削減

[ソース](https://openai.com/news/)

### An Alien Mind (OpenAI)

2026-09-06 公開の安全性エッセイ。**再帰的自己改善が現在の路線の延長線上で到達しうる**という認識を示したうえで、「極度の慎重さ」をもって臨むこと、また状況によっては**規模拡大の一方的な停止も辞さない**と表明している。

[ソース](https://openai.com/news/)

### OpenAI「Research acceleration: The view inside OpenAI」

2026-09-06 公開。昨秋に公言していた「**2026年9月までに自動研究インターン**」という目標の達成を発表した。次の目標は **2028年3月の自動AI研究者**。

[ソース](https://openai.com/news/)
